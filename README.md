# 2.4G 键鼠电量监控软件 (Win10 原生风格)

一款专门针对 **雷蛇鼠标（Razer DeathAdder V3 Pro 等系列）** 与 **VGN 键盘（VGN S99 / VXE 系列等 2.4G 接收器方案）** 开发的轻量级原生桌面电量监控工具。

## ✨ 核心特性

1. **Win10 风格极简托盘显示**
   - 默认采用**单图标上下分栏的电池条**，可在设置中切换为纯数字百分比（上行鼠标、下行键盘，支持上下顺序互换）。
   - 支持实时颜色状态反馈：
     - **绿色**：正在插线充电中。
     - **红色**：电量低于警报阈值（默认 20%）。
     - **暗灰**：设备进入省电休眠（自动缓存最后一次有效电量，绝不跳零误报）。
   - 在设置中提供“双横向微型电池条”与“纯数字”一键切换。

2. **Win10 原生任务栏浮窗（Flyout）**
   - 鼠标左键单击托盘图标，在任务栏右下角弹出完全符合 Windows 10 风格的圆角/亚克力质感浮窗卡片。
   - 详细呈现鼠标与键盘的连接状态、电量百分比、充电标识与“上次更新”时间。
   - 包含“立即刷新”与“打开设置”快捷入口，失去焦点自动隐退。

3. **Win10 原生系统通知中心（Toast）弹窗**
   - 跌破设定阈值（默认 20%）时触发一次系统右下角 Toast 弹窗通知。
   - 低于 10% 触发紧急低电量告警。
   - 在未重新充入电量前杜绝重复弹窗打扰。

4. **极低资源占用 + 键盘省电优先**
   - 鼠标：每 4 秒读一次 Razer 守护引擎日志，开销低于 1ms。
   - 键盘：**不做后台定时轮询**。只在启动、点“立即刷新”、按键后（Raw Input，默认开启、30 分钟冷却）、有线充电时查询，休眠期间零 RF 查询。
   - 键盘休眠时不会主动唤醒，只显示上次缓存值；日志 `monitor.log` 位于源码目录，超过 256KB 自动轮转。
   - CPU 占用接近 0.0%，内存占用极小。

5. **开箱即用与开机自启**
   - 包含设置面板，可自定义开机自启动（直接写入当前用户的 Windows Run 注册表）、低电量阈值、鼠标刷新间隔与界面主题。

## 🔋 键盘省电设计（关键）

2.4G 键盘休眠后，任何 `xr.power_info` 查询都会经接收器把它叫醒。旧版本每 60 秒（充电时 15 秒、休眠后 180 秒）查询一次，短于键盘自身的空闲休眠时间，导致键盘永远不休眠、电量快速下降。

现在：

- 后台**不再定时查询键盘**；空闲时不会产生任何 RF 请求。
- 打开浮窗显示缓存值 + 上次更新时间；需要最新数据时点“立即刷新”。
- 开启“按键后自动刷新”时，用 Raw Input 只记录“有按键活动”，按键停止 3 秒后查询一次，且每 30 分钟最多一次；不记录、不拦截、不注入任何按键内容。
- 10 分钟没有按键活动就本地标记“休眠 · 缓存”，不再探测。
- 键盘有线充电时改为每 60 秒查询一次（USB 供电，不消耗键盘电池）。

## 🚀 启动方式

- **静默后台启动（推荐，无黑框）**：双击运行项目根目录下的 `启动键鼠电量监控(无控制台黑框).bat`。
- **命令行启动调试**：运行 `python battery_monitor.py`。
